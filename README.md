This is the source code of the [UKPersonalFinance Wiki](https://ukpersonal.finance)

- Pages can be found as Markdown files in [src/content/docs](/src/content/docs)
- Images are in [src/assets](src/assets)
- The sidebar/menu is configured in [astro.config.mjs](astro.config.mjs), documentation for which can be found [here](https://starlight.astro.build/guides/sidebar/)
- Changes are automatically deployed to [https://staging.ukpersonal.finance](https://staging.ukpersonal.finance) (username: any, password: `flowchart`)
- Once you're happy with your staging deployment, to progress to [https://ukpersonal.finance](https://ukpersonal.finance) it needs approval from a [moderator](https://github.com/orgs/UKPersonalFinance/teams/moderators)
