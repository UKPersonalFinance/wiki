## Have you seen the flowchart? ⤵️

The flowchart is clickable! Each step will take you to a page with more
detailed information and explanations.

This flow chart is maintained by the Reddit UKPersonalFinance community. We
aren't active on other social media platforms, so please [join us on
reddit](https://www.reddit.com/r/UKPersonalFinance). If you have any
questions about the flow chart, please mention which step you are currently
working on.

If your device does not support the format below, you can find an image
version at [flowchart.ukpersonal.finance](https://flowchart.ukpersonal.finance).

Current version: 3.0.10
Last updated: 2025-12-22
